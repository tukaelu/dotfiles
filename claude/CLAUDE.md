# CLAUDE.md

## 基本ルール

- よく思考すること
- 回答の前に客観的な評価をすること
- 挨拶や不要な前置きは省いて結論から述べること
- 重要な判断や事実主張は必ず一次情報（公式ドキュメント、ソースコード、実行結果など）に基づくこと
- 不明な点は必ずユーザーに確認を行い、憶測で進めないこと
- 日本語でコミュニケーションすること

## コーディングのルール

- YAGNI に従い、要求にない抽象化や将来拡張のための層を追加しないこと
- 実装した変更については、応答テキスト内でその意図と要点をユーザーに説明すること（コード内コメントは原則として最小限に留める）

### Git 操作のルール

- コミット・プッシュはユーザーの明示的な指示がない限り行わないこと
- `git reset --hard` や `git push --force-with-lease` など破壊的操作は実行前に確認すること
- 強制的にプッシュする必要がある場合は `--force` ではなく `--force-with-lease` を使用すること
